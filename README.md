## About

**CreamDevelopers** is a development team under **CreamNetworksGroup**.
We build Discord bots, web applications, Minecraft Bedrock Edition addons, and the infrastructure that runs them.

Our products share a simple, consistent design language: flat UI, a single accent color, and full dark / light mode support.
